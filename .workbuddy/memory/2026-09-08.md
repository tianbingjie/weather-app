## iOS 移动端 UI 适配优化（已完成）

修改文件：`static/css/style.css`、`templates/index.html`（仅 head meta）。

主要修复：
1. **grid 子项 min-width bug（真实布局错乱根源）**：`.grid` 轨道被 `.scroll-row`（24 个小时项 ≈1700px）的 min-content 撑开，移动端 `.card.wide` 实际渲染 1724px 宽。修复：`.card{min-width:0}` + grid 轨道改 `minmax(0,1fr)`。
2. **选择器错误**：CSS 写的 `.results{}` 与 HTML `id="results"` 不匹配，搜索下拉从未定位，改 `#results`。
3. **iOS 视口高度**：`100vh` → 追加 `-webkit-fill-available` 和 `100dvh` 回退链。
4. **安全区**：`.shell` padding 叠加 `env(safe-area-inset-*)`（含 700px 媒体查询内的覆盖）。
5. **iOS 渲染细节**：`-webkit-text-size-adjust:100%`、按钮/输入框 `appearance:none` + `touch-action:manipulation`、输入框 `min-width:0`、预警/分钟降水 `overflow-wrap:anywhere`、新增 380px 断点。
6. HTML head 增加 `apple-mobile-web-app-capable`、`apple-mobile-web-app-status-bar-style=black-translucent`、`format-detection=telephone=no`。

验证方式：playwright-core + 系统 Chrome（executablePath 指向 /Applications/Google Chrome.app），模拟 iPhone UA 注入 mock 数据调用全局 `render()`，检测 390/320/1280 三视口无横向溢出。检测脚本 /tmp/weather-check.js（临时）。
注意：本项目后端依赖未装（无 uvicorn），验证用静态服务器 8765 端口；agent-browser 自带 Chromium 下载在本机网络下两次超时失败。
